A seed marked unused belongs to a deterministic fixture that draws nothing. The order and bootstrap seed is the acceptance interval's `seed`: SplitMix64 over the campaign seed XOR the first eight bytes of the SHA-256 of the cell key; it seeds the xoshiro256** generator of `dev/tools/tuning-campaign-support/src/abtest.rs` that counterbalances the pair order and draws the bootstrap resamples, at the file digest each heading names.

What the frozen harness's conversion probes time: `setup` is one-shot fixture or code construction; for the packed BCH cells `pack` is one `encode_workspace()` construction, because the families pack messages inside the timed call, and `batch_fill` regenerates the batch with the fixture generator, a harness cost a consumer replaces with a copy of its own data; `dispatch` is the family selection `encode_batch_into` performs per call. Two corrections to the frozen receipts: their LDPC `setup` probe constructed the DVB-T2 short-frame code whatever the declared length, so for the $n = 64800$ cells it times the short code, not the normal one; and their LDPC `unpack` proxy appended 32448 bits (507 words) where the syndrome has 32400. The harness now constructs the declared code and appends one bit per check; the receipts keep their bytes.
