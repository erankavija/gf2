Rework note:
  The benchmark now calls `matvec_with_prefetch_distance(x, 16)` explicitly for
  `block_csr_prefetch`. The public block-CSR `matvec()` default was changed to
  no software prefetch because all measured prefetch distances hurt wall time on
  this LDPC-sized fixture.

Interpretation:
  * CSR remains faster on the measured LDPC-sized fixtures.
  * The no-prefetch block layout is close on 4096x8192_w6 but is still slower
    than CSR in this rework run.
  * Software prefetch instructions are emitted (see crates/gf2-core/src/sparse.asm.txt)
    and prefetch improves block-CSR L1d miss rate versus no-prefetch in the
    fixed-iteration harness, but it consistently hurts wall time.
