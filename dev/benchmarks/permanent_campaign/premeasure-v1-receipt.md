# Premeasurement v1 cohort receipt

This receipt binds the immutable `premeasure-v1` cohort used by the permanent
campaign's backend freeze. It records every planned process position and keeps
measurement outcomes separate from backend-selection decisions. The source
cohort is read-only; no failed or censored process is replaced.

## Cohort identity

The fixed plan contains 60 cells, two configurations per cell, and 12 fresh
processes per configuration: 1,440 process positions. Positions run in three
sessions: `20260824T055928Z-726522` (540 positions),
`20260824T230036Z-87505` (468 positions), and
`20260825T230033Z-2571980` (432 positions). Every ledger row records source
revision `1350d5b46cd541093882537a89ea35db05a7afc5`. Every candidate row records
benchmark executable SHA-256
`1198cce47de06a6793fd1b5d880d559f020acffebc3d237137fa5c1326775606`.
The session provenance columns retain the complete binary chain and wrapper
invocation. The runtime-observed host is an AMD Ryzen 9 5900X with an AMD
Radeon RX 6950 XT (`gfx1030`) under ROCm 7.2.4.

The collector applies the recorded D-01 rule to accelerator scratch files: the
native-$M$ second row is the process measurement, while the coerced first row
remains an unused replicate in the source scratch file. This projection is
fixed by grid-slot identity and does not inspect the measured rate.

## Reproduction

From the repository root:

```console
$ python3 dev/benchmarks/permanent_campaign/summarize_premeasure_v1.py
wrote dev/benchmarks/permanent_campaign/premeasure-v1-cell-summary.csv
sha256=a881379d2066e764af4e7b6aa459b5f81c0562d67c42f9ddb81362b325ad65bd
```

This command reads committed evidence only. It runs no benchmark, accesses no
device, draws no campaign matrix, and mutates no campaign dataset.
