# ResearchGate full-text lead identification

## Lead and outcome

The lead advertised an author-uploaded public full text for the title
“Soft-decision decoding of linear block codes based on ordered statistics.”
The downloaded file is not the 1995 IEEE Transactions on Information Theory
article by Marc P.C. Fossorier and Shu Lin (DOI `10.1109/18.412683`). It is a
different work whose longer title begins with the same phrase. The lead is
therefore a title-collision false positive, and the 1995 article remains
unobtained.

Fossorier), the 1999 venue, and the multilevel-signaling scope distinguish the
file from the two-author 1995 IEEE article. No content from the local PDF is
redistributed by this audit.
