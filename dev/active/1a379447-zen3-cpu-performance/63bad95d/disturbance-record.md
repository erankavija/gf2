# Profile-family campaigns: host load and dispersion

> **Diátaxis Type:** Reference

Generated by `survey/make-disturbance-record.py` from the committed receipts of the families `survey/planned-families.json` plans. The relative half-width of an interval is `max(s - l, u - s) / s`.
