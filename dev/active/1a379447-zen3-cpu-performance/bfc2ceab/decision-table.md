# Decision table: checked or unchecked kernel entry points

> **Diátaxis Type:** Reference

Generated by `survey/make-inventory.py`; the rows are those of [`inventory.md`](inventory.md), the instruction counts those of [`survey/instruction-counts.json`](survey/instruction-counts.json) under its `rule`. An instruction count is no timing: it states what the prototype of the check holds outside panic blocks, with each loop body counted once.

Option (a) puts a release-mode check in the safe entry point, in the form of the M4RM Gray-table builders. Option (b) makes the kernel an `unsafe fn` with the condition under Safety, so each caller holds an `unsafe` block with a `// SAFETY:` comment. `gf2-core`, `gf2-algebra` and `gf2-coding` deny `unsafe_code` (`core-denies-unsafe`, `algebra-denies-unsafe`, `coding-denies-unsafe`), so a production call site there cannot hold that block: for such an interface option (b) keeps a checked safe entry in the kernel crate, at the same or a coarser grain, and makes only the inner kernel `unsafe`.

Decision of the invoker, 2026-10-07 ([`decisions.json`](decisions.json)): Checked safe entries (option a) for every interface whose check is recorded not-worse; for the two sparse-row interfaces (SmallPrimeSpmmRowFn, MediumPrimeSpmmRowFn) hoist the check: an `unsafe fn ..._unchecked` row kernel inside gf2-kernels-simd plus one safe entry that validates column indices once per product, or reliance on the sparse type's constructor invariant if it guarantees `col < cols`. Fallback, also approved: if the call-site analysis shows no sound coarser grain, keep the per-row check and record the measured cost as accepted under REQ-04. The `Decision` column states it per class, and the tree holds the decided form of every entry point.

Ruling of the invoker, 2026-10-07: REQ-04 for the hoisted sparse form: a new single-purpose family, pilot and then confirmation in consecutive benchmark windows; arms are the hoisted checked form of the tree against the unchecked baseline, the baseline built inside the arm crate from the kernel crate's own `unsafe` row kernel driven by the pre-change row loop, so both arms come from one tree and one closure.

Ruling of the invoker, 2026-10-11: REQ-04 for the hoisted sparse form: the exploratory measured cost of the per-product check is accepted as the two pilot receipts of the family `sparse-product-check-cost` record it, without a confirmation; no new family and no further measurement. The ruling holds with both disturbances in view: the load average the first pilot's receipt records at the start of its session, and the contended window of the second pilot, whose receipt records the load at the start of its session.

The last column names, for each interface, its rows in the family's [tables](../../../bench_results/bfc2ceab/tables.md), which `survey/make-tables.py` writes from each stage's acceptance summary with the pair count, interval and outcome of every cell. Each row carries the role, outcome and decision its summary records: an exploratory row sizes the confirmation and decides nothing, and a confirmatory row is the family's recorded cost of the check. Verdicts: pilot `accepted`, confirmation `accepted`; the finding counts stand on the tables' Source lines. An interface without a row has no cell in the family.
