# gf2 Lean 4 proofs

This Lake package holds Lean 4 translations of selected `gf2-core` and
`gf2-algebra` functions and the hand-written proofs over them. The workflow for
building, regenerating and adding proofs is
[Run and extend the Lean 4 proofs](../docs/how-to/formal-verification.md).

| Path | Contents |
|---|---|
| `lakefile.lean`, `lake-manifest.json`, `lean-toolchain` | Package definition, dependency pins and Lean toolchain |
| `Gf2Core.lean`, `Gf2Algebra.lean` | Library roots; a module is built when its root imports it |
| `Gf2Core/`, `Gf2Algebra/` | Translations generated by `scripts/verify-lean.sh`, plus `FunsExternal.lean` |
| `Gf2Core/Proofs/`, `Gf2Algebra/Proofs/` | Hand-written definitions and theorems; each file's header states its subject |
| `WORKAROUNDS.md` | Translation defects and the post-processing that handles each |
